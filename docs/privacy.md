# Publication and Safety Notes

This public repo avoids redistributing sensitive generated content.

## Excluded

- generated images,
- unsafe qualitative examples,
- prompt CSVs,
- per-sample JSON outputs,
- model checkpoints,
- Hugging Face caches,
- course instruction files.

## Included

- aggregate metrics,
- method summary,
- limitations-aware interpretation,
- small utility code,
- link to the existing public group implementation.

The project topic involves unsafe image generation, so the public portfolio version emphasizes methods and aggregate evaluation rather than visual examples.
