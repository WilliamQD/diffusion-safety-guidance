# Publication Audit

This repository is a curated public portfolio summary of a collaborative diffusion-safety final project.

## Published

- Polished README.
- Public-safe method, result, privacy, and contribution notes.
- Small utility code for adaptive guidance scheduling and Pareto analysis.
- Synthetic unit tests.
- Link to the existing public group implementation.

## Excluded

- Generated image samples.
- Unsafe qualitative galleries.
- Raw prompt CSVs.
- Per-sample JSON outputs.
- model weights and caches.
- private course instructions.
- duplicated coauthor-owned implementation files.

## Rationale

The goal is to showcase William's research analysis and technical-writing contribution without overclaiming ownership of collaborative code or redistributing sensitive/generated artifacts.
